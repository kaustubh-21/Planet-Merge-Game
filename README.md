# Pandu 🌌

A physics-based cosmic merge game where planets collide and evolve from Moon to Supernova.

## ✨ Features

- **11 Planetary Stages**: Moon → Mercury → Mars → Earth → Neptune → Saturn → Jupiter → Sun → Sirius → Black Hole → Supernova
- **Realistic Physics**: Matter.js powered gravity and collisions
- **Beautiful Visuals**: Neon-Zen space theme with glowing planets and particle effects
- **Procedural Audio**: Dynamic sound effects using Web Audio API
- **Mobile Ready**: Touch controls and PWA support

## 🚀 Quick Start

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build
```

## 🎯 How to Play

1. **Position**: Move your mouse horizontally to position the planet
2. **Drop**: Click to drop the planet into the Cosmos Jar
3. **Merge**: Match two identical planets to create the next stage
4. **Survive**: Don't let planets pile above the Event Horizon!

## 🛠️ Tech Stack

- **Vanilla JavaScript** - No framework overhead
- **Matter.js** - 2D physics engine
- **Vite** - Fast build tool and dev server
- **Web Audio API** - Procedural sound generation
- **Canvas API** - Custom rendering with effects
